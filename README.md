# Programming-fundamentals
🛒 Grocery Store Management System
A Grocery Store Management System developed in C++ as a Programming Fundamentals (PF) Lab Project. This console-based application helps manage grocery store operations, including product inventory, pricing, stock management, and sales billing.

The system provides separate functionalities for managing products and processing customer purchases, making basic grocery store operations easier and more organized.
📌 Project Information
- Project Name: MF-Supermart – Grocery Store Management System
- Language: C++
- Course: Programming Fundamentals (PF) Lab
- Project Type: Console-Based Application
- Concepts Used: Functions, Arrays, Loops, Conditional Statements, File Handling, and Structures of Modular Programming.
✨ Features
1. Product Management
- Add new grocery products.
- Delete existing products.
- Store product information, including name, product ID, weight, manufacturing date, and expiry date.
- Maintain product records using file handling.
2. Inventory Management
- Update product quantities.
- Check the remaining stock of a product.
- Search products using their unique product IDs.
3. Price Management
- Assign and update product prices.
- Search and display the price of a particular product.
4. Sales and Billing
- Process customer purchases.
- Select multiple products using product IDs.
- Enter the required purchase quantities.
- Automatically calculate the total bill.
- Reduce available stock after successful purchases.
- Generate an invoice containing purchase details.
5. File Handling
The system uses file handling to store and retrieve product and sales information.
File Name	Purpose
items.txt	Stores product inventory information
invoice.txt	Stores customer purchase and billing details
new.txt	Used for reading product records in the initial implementation🛠️ Technologies & Concepts
